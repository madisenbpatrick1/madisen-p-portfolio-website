# 💻 Madisen Patrick — Portfolio Website

A personal portfolio built with **React + TypeScript + Tailwind CSS**.  
It showcases my engineering projects, design work, and writing in a clean, modern interface.

## 🚀 Features
- Responsive React UI with Tailwind
- Organized code structure (components, hooks, data)
- Reusable layout with Navbar + Footer
- Smooth fade-in animations via custom hooks

## 🛠️ Tech Stack
- React (TypeScript)
- Tailwind CSS
- Vite or CRA (depending on setup)
- GitHub Pages / Netlify (for deployment)
